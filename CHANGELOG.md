# Changelog

## 1.0.0 — Scrabble Room

- TypeScript/Vite static app with GitHub Pages deployment.
- 2–4 player WebRTC rooms with host-coordinated turns and redacted state.
- Standard English bag, TWL validation, premium scoring, exchanges, passes, and final tile deductions.
- Friendly-room mode with unique words and a neutral centre, plus the selectable official ruleset.
- Deep-link joining, visible room code/invite during play, connection retries, and a fixed square grid layout.
